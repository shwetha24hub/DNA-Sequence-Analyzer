# 🧬 DNA Sequence Analyzer

An interactive bioinformatics web application built using Python and Streamlit to analyze DNA sequences.

## 🚀 Live Demo

Paste your deployed Streamlit website link here.

## ✨ Features

* DNA sequence validation
* DNA sequence length calculation
* Nucleotide composition analysis
* GC content calculation
* DNA-to-RNA transcription
* Complementary DNA generation
* Reverse complement generation
* Interactive nucleotide composition chart

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas

## ▶️ Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

## 🎯 Project Objective

To develop a beginner-friendly bioinformatics tool that performs basic DNA sequence analysis through an interactive web interface.
